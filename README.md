# 🛡️ IFIX VPN - Commercial Professional VPN Application

![IFIX VPN Logo](app/src/main/res/drawable/ic_launcher_foreground.xml)

یک اپلیکیشن اندروید تجاری، حرفه‌ای و اختصاصی با برند **IFIX VPN** طراحی شده با نیتیو کوتلین، جت‌پک کامپوز و متریال دیزاین ۳.

---

## 🚀 ویژگی‌های اصلی اپلیکیشن IFIX VPN

- **طراحی مدرن و اختصاصی**: تم تیره نوی سورمه‌ای و فیروزه‌ای، انیمیشن دکمه اتصال، نمایش زنده سرعت آپلود/دانلود و پینگ.
- **سیستم فعال‌سازی لایسنس (License Activation)**: فرم دریافت لایسنس تجاری، بررسی اعتبار از بکتد، ذخیره‌سازی امن محلی و کد کلیدهای تست برای بررسی آسان.
- **پشتیبانی از پروتکل‌های VPN و Subscription**:
  - پشتیبانی کامل از **VLESS**, **VMess**, **Trojan**, **Shadowsocks**, **Xray**, **V2Ray**.
  - وارد کردن لینک اشتراک با کیپ‌بورد، لینک HTTPS یا QR Code.
- **مدیریت سرورها**: لیست کامل سرورها بر اساس کشور، فیلتر پروتکل، مرتب‌سازی پینگ و سنجش تست تاخیر لحظه‌ای.
- **بررسی بروزرسانی آنلاین و Remote Config**: نمایش اطلاعیه‌های مدیریتی و پاپ‌آپ نسخه جدید با امکان Force Update.

## 📚 راهنمای کامل گیت و گیت‌هاب برای افراد مبتدی (Git & GitHub Beginner Tutorial)

اگر برنامه‌نویس حرفه‌ای نیستید، با دنبال کردن مراحل زیر می‌توانید پروژه خود را به‌راحتی در گیت‌هاب مدیریت کنید و فایل APK بگیرید:

### ۱. مفاهیم پایه به زبان ساده:
- **Repository (مخزن/ریپازیتوری)**: پوشه آنلاین پروژه شما در گیت‌هاب.
- **Commit (کامیت)**: ذخیره کردن نقطه تغییرات جدید کد.
- **Push (پوش)**: ارسال تغییرات کامیت‌شده از سیستم شما به ریپازیتوری آنلاین گیت‌هاب.
- **Pull (پول)**: دریافت آخرین کدها از گیت‌هاب به سیستم شما.
- **Branch (شاخه)**: نسخه‌ای مستقل برای ساخت ویژگی جدید قبل از متصل کردن به شاخه اصلی (`main`).
- **Release (انتشار)**: نسخه نهایی برنامه شامل فایل نصب APK و AAB آماده دانلود.

---

### ۲. نحوه ساخت Repository جدید در GitHub:
1. وارد حساب کاربردی خود در [GitHub.com](https://github.com) شوید.
2. روی دکمه **New Repository** یا آیکون `+` کلیک کنید.
3. نام ریپازیتوری را `ifix-vpn-android` قرار دهید.
4. گزینه **Private** (خصوصی) را انتخاب کنید تا سورس کد شما محفوظ باشد.
5. روی **Create repository** کلیک کنید.

---

### ۳. نحوه ساخت خودکار APK و AAB با GitHub Actions (بدون نیاز به سیستم قوی یا VPS):
این پروژه دارای فایل کاملا آماده `.github/workflows/android-build.yml` است.
هر زمانی که شما کدهای جدید را به گیت‌هاب **Push** کنید:
1. گیت‌هاب به صورت خودکار پروژه را چک می‌کند.
2. کدهای Kotlin و Gradle را کامپایل می‌کند.
3. خروجی **APK** (برای نصب مستقیم روی گوشی) و **AAB** (برای انتشار در گوگل پلی) را تولید می‌کند.
4. **نحوه دانلود فایل APK**:
   - وارد صفحه پروژه در GitHub شوید.
   - به تب **Actions** بروید.
   - روی آخرین اجرای Build کلیک کنید.
   - در بخش **Artifacts** در پایین صفحه، روی `IFIX_VPN_Debug_APK` کلیک کنید تا فایل zip حاوی APK دانلود شود!

## 🛠️ راهنمای اجرای Backend و پنل مدیریت سرورها

پروژه دارای بکتد کامل Node.js در پوشه `/backend` است:

```bash
cd backend
npm install
npm start
```

### Endpoints اصلی REST API:
- `POST /api/license/activate` : فعال‌سازی کلید لایسنس
- `POST /api/license/check` : بررسی اعتبار لایسنس
- `GET /api/server/list` : دریافت آخرین لیست سرورها
- `GET /api/config` : دریافت تنظیمات Remote Config

## 📱 راهنمای انتشار در Google Play Store:
1. در حساب کنسول توسعه‌دهندگان گوگل پلی ثبت نام کنید.
2. از تب **Actions** در گیت‌هاب فایل `IFIX_VPN_Release_AAB` را دانلود کنید.
3. در کنسول گوگل پلی یک **App** جدید با نام **IFIX VPN** بسازید.
4. فایل `.aab` را در بخش Production / Internal Testing آپلود نمایید.
